FAQ

常见问题

Is this a professional SPL meter? Caju is a phone sound meter for everyday noise checks (home, office, street). Phone microphones vary, so treat readings as a useful estimate, not lab-grade calibration.

这是专业声级计吗？ Caju 是手机分贝仪 / 噪音计，适合家里、办公室、路边的日常测量。手机麦克风差异较大，读数适合参考，不能替代实验室校准设备。

Does it record audio? No. The microphone is used only to compute dB while measuring. History stays on the device.
