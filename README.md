# dB Meter Caju

Free, ad-free **decibel meter / sound meter** for Android. Measure ambient noise in dB with live min, avg, peak, percentiles, and history.

[![Get it on Google Play](https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png)](https://play.google.com/store/apps/details?id=com.bytemyth.decibel_meter)

Website: https://cute-satsuma.github.io/decibel_meter/

## Features

- Real-time decibel / noise level measurement
- Statistics: min, avg, peak, P50 / P90 / P95
- Measurement history on device
- Dark mode and 10 languages
- No ads, no account, microphone used only while measuring
